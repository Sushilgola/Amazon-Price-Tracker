Amazon Price Tracker using Python

A Python-based Amazon Price Tracker that monitors the price of a product on Amazon and sends an SMS notification when the product price drops below a specified target price. The project uses web scraping with Selenium to extract product information and Twilio to deliver SMS alerts.

🚀 Features

🔍 Automated Price Tracking: Fetches the latest available product price from Amazon.

🎯 Target Price Monitoring: Compares the current price with your desired price.

📩 SMS Notifications: Sends price-drop alerts using the Twilio API.

🌐 Web Scraping: Uses Selenium to interact with and extract information from web pages.

⚙️ Customizable: Configure the product URL and target price according to your requirements.

🐍 Python-Based: Simple and easy-to-understand implementation.
